Prompt
Prompt
Attached is a schedule export (CSV: Activity ID, Name, Duration, Start, Finish, Predecessors, Total Float, Resource). Target finish: {date}. Current finish: {date}.

1 Identify the critical path and the near-critical chains (float under 5 days).
2 Propose up to eight compression options: crash (add crew/shift), fast-track (overlap), re-sequence, or scope split. For each: activities affected, days saved, added cost or risk (low/med/high), what must be true for it to work.
3 Rank by days saved per unit of risk.
4 State which options stack and which conflict.
5 Do not add or remove logic ties you cannot see in the export; flag assumptions.

Return as a table, then a 100-word recommendation.
