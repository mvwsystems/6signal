Prompt
Prompt
Attached: the schedule of values (G703 columns A–I from last period) and the current schedule export with percent complete per activity. Map each SOV line to the schedule activities that make it up (ask me if a mapping is ambiguous, do not guess). Compute this period's work completed per line, weighted by activity cost if provided, else by duration.

Return the G703 table: Item | Description | Scheduled value | From previous | This period | Stored materials (leave for me) | Total completed | % | Balance to finish. Then flag: lines that moved more than 20 points, lines at 100% with open punch items, lines with zero movement for two periods.
