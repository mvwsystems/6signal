Daily Report Autopilot

Six fields of the daily report fill themselves from sources that already exist. The super adds two sentences and submits before five.

Build steps
  1. Field 1 Weather: pull hourly observations from a weather API for the site coordinates.
  2. Field 2 Manpower: read sign-in (Procore Timesheets, ACC, or a Google Form the foremen fill).
  3. Field 3 Equipment: read the equipment log or yesterday's report plus a one-tap "same as yesterday" form.
  4. Field 4 Deliveries: read delivery tickets photographed to a shared folder (OCR step).
  5. Field 5 Work performed: read the schedule activities planned for today plus the super's voice memo, transcribed.
  6. Field 6 Issues/delays: pull RFIs opened today and any inbox email tagged delay.
  7. 4:30 PM: compile all six with the prompt below into your report template; post as draft to the super.
  8. Super edits two sentences, submits by 5. Measure: percent of reports submitted same day.
Prompt inside the automation
Prompt inside the automation
Compile a daily construction report for {project}, {date} from the sources below. Use the template headings exactly. Plain, factual, past tense, no adjectives. Where a source is empty, write "None reported", never invent. Sources: WEATHER {…} MANPOWER {…} EQUIPMENT {…} DELIVERIES {…} PLANNED WORK {…} VOICE MEMO TRANSCRIPT {…} ISSUES {…}
