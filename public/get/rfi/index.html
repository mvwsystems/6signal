Build steps
  1. Trigger: new RFI created in Procore or ACC.
  2. Automation pulls the RFI text plus the referenced sheets and spec sections from the project folder.
  3. Sends to the assistant with the prompt above.
  4. Posts the draft as a private comment on the RFI, tagged DRAFT.
  5. PM edits, then submits the official response. Track median days-open per project on a dashboard.

Prompt inside the automation
You are the project engineer on {project}. Draft a response to the RFI below for the PM to review. Use only the attached spec sections and drawing sheets; cite them by section and sheet number. If the answer requires the architect or engineer, say so and draft the forwarding note instead.

RFI: {paste RFI question, sheet references, subcontractor}

Return:
1 Proposed response (under 150 words, direct, no hedging)
2 Sources cited (spec section, sheet, detail)
3 Cost or schedule impact: yes / no / unknown, one line why
4 Open questions for the PM before sending
5 Confidence: high / medium / low
