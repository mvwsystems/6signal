Prompt
Prompt
Attached is a clash report export (CSV: Clash ID, Element A, Element B, Discipline A, Discipline B, Level, Grid, Distance, Status). Triage it:

1 Group clashes that share the same element pair, level and cause into one issue; count how many each group collapses.
2 Classify each group: tolerance (under {25}mm, ignore), duplicate, resolvable by rule (e.g. pipe below duct per standard, insulation overlap), or needs decision.
3 For resolvable-by-rule, state the rule and which discipline moves.
4 For needs decision, write a one-line agenda item with the two disciplines and a proposed option.
5 Summary: total clashes → groups → needs-decision count.

Return the agenda items first, then the full grouping table.
