Prompt
Attached: photos from the weekly walk of {floor/area}, {project}, {date}, labeled by room. For each room estimate percent complete per trade using these stage ladders: Framing (layout 10, top track 30, studs 60, blocking 80, inspected 100). Drywall (hung 40, taped 60, finished 90, primed 100). MEP rough (sleeves 20, mains 50, branches 80, inspected 100). Ceiling grid (wire 30, main runners 60, cross tees 90, tile 100). Flooring (prep 30, installed 90, base 100). Paint (prime 40, first coat 70, final 100).

Return a table: Room | Framing | Drywall | MEP rough | Ceiling | Flooring | Paint | Notes. Mark any estimate from a partial view with "~". Then compare to last week's table {paste} and list rooms with zero movement.
