Setup · twenty minutes
  1. Export the project manual as searchable PDF (OCR it in Bluebeam if scanned). Split into divisions if over 300 pages.
  2. Create a Claude Project (or NotebookLM notebook) named {project} — Specs. Upload the PDFs plus the addenda.
  3. Set the project instructions: "Answer only from the uploaded documents. Cite section number, paragraph and page for every statement. If not found, say not found."
  4. Invite the PMs, supers and the project engineer.
  5. Pin the ten standing questions below as a note.
  6. Re-upload when an addendum or ASI is issued; name files with the date.
Ten standing questions
Ten standing questions
Standing questions:
1 What is the required cure time and testing for {material} per the spec?
2 Which section governs {product} and what submittals does it require?
3 What are the warranty terms for {system}?
4 What mock-ups are required and who approves them?
5 List all required third-party inspections in Division {n}.
6 What tolerances apply to {work}?
7 What does the spec say about substitutions and the deadline?
8 Which sections reference {standard, e.g. ASTM C150}?
9 What closeout documents are required for Section {xx xx xx}?
10 Are there any conflicts between Section {a} and Section {b}?
