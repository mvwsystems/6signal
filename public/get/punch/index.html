Prompt
Prompt
Attached is a site photo from {project}, {location: floor / room / grid}. Identify every visible deficiency, incomplete item or damage that would appear on a punch list.

For each, return one CSV row: Title (under 8 words) | Description (one sentence, what and where in the frame) | Trade (drywall, paint, electrical, mechanical, plumbing, flooring, doors/hardware, glazing, other) | Location ({location} plus position in frame: e.g. north wall, left of door) | Priority (1 life-safety, 2 function, 3 cosmetic).

Only list what is visible. If an item may be work in progress rather than deficient, add "(verify)" to the title. Return the CSV header first.
