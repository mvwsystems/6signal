Prompt
Compare the two attached drawing sheets: {Sheet A, e.g. A2.01 Floor Plan} and {Sheet B, e.g. S2.01 Framing Plan}. Find every location where they disagree or where one shows something the other omits.

For each: Grid reference | What Sheet A shows | What Sheet B shows | Type (dimension / opening / elevation / element missing / annotation) | Suggested RFI wording (one sentence).

List the top five by construction impact first. Keep grid references exact; if a grid line is unreadable, say so.

Run on: A-plan vs S-plan; A-RCP vs M-plan; A-sections vs S-sections; A-door schedule vs A-plan; C-site vs A-site; E-plan vs A-RCP.
