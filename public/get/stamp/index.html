Submittal Pre-Review Prompt

Compare the submittal to the spec section before a human opens it. The reviewer gets a comment list, not a stack.

Prompt
Prompt
You are reviewing a submittal against the specification. Attached: the submittal ({type: product data / shop drawing / sample}) and spec section {section number and title}.

Return a table: Spec paragraph | Requirement | Submittal shows | Status (Complies / Deviates / Not shown) | Comment for the submitter.

Then:
- Count of Deviates and Not shown
- Recommended stamp: No Exceptions Taken / Make Corrections Noted / Revise and Resubmit / Rejected, with a two-sentence reason
- Anything that needs the design team, listed separately

Do not infer compliance from a brand name. If the submittal does not show a required value, mark Not shown.
