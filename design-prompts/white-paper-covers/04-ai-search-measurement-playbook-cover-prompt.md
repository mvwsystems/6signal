## 3. Visual concept

A **field measurement instrument** observing AI answers. The paper's argument is that one screenshot is not measurement — real measurement is a calibrated instrument: fixed prompt signals entering, repeated observations logged, and four distinct detected states (MENTION, CITATION, SOURCE, RECOMMENDATION) separated cleanly. The cover shows an observation matrix: rows of prompt signals, columns of repeated observations, mostly gray/dim readings with variance visible — and **one acid-yellow verified signal** standing out as a confirmed recommendation. It should read as an intelligence measurement apparatus, not analytics software: this is a scientific instrument pointed at answer engines. The single yellow reading carries the thesis — signal separated from noise by disciplined observation.

## 6. Diagram system

A rectangular observation matrix: ~6 rows (prompt signals entering from the left as thin lines) × ~8 columns (repeated observations). Cells contain small tick/dot readings in three gray weights representing variance across runs. Row-end state markers use the four detected states as tiny mono tags. A thin baseline rule runs beneath with calibration ticks labeled BASELINE. Exactly one cell is filled #E6FF00 with its path traced back to its prompt line in yellow — the verified signal. Corner registration marks, faint coordinate numerals along edges. Labels drawn ONLY from: PROMPT · MENTION · CITATION · SOURCE · RECOMMENDATION · VARIANCE · BASELINE · OBSERVATION SET · SELECTED.
